## Upgrade law

External WASI, planner, semantic, federation, recovery, or model-compute output is **evidence/candidate state only**. CASTLE admits it only when exact source SHA, exact subject, content digests, and bounded resource limits hold. Portable-runtime agreement, independent plan verification, and FOND/TLA+ differential agreement are separate courts. Provider failure removes only that recovery edge; it does not widen authority or create an alternate DO path. Consequential execution remains exclusively behind CASTLE's existing opaque `ConstructAdmission -> BRCE -> DO -> OCEL/receipt` boundary.
